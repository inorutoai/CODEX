# デザインと運用判断

- PCは左ナビゲーション、概要カード、優先事項テーブル、操作履歴を配置。タブレットで余白を調整し、スマートフォンでは上部ナビと2列カード、単列コンテンツへ変更。横幅が必要な表は表内だけスクロール可能。
- 黒い共通ヘッダーとオレンジの主操作、明るい本文を採用。提案色は `#ed6d29` / `#18191d`。承認済み規定が届けばCSS変数から変更。過剰な装飾やアニメーションは使わない。
- 緊急・高・中・低、未対応・対応中・解決済みは文字ラベルと色で区別。読み込み、空データ、失敗、保存成功、削除確認を用意。フォーカス表示、本文スキップ、ラベル付き入力、native dialogを使用。
- 既存採用サイトと操作手順を残し、新しいセキュリティ管理用の操作手順をアプリにも掲載。
- 未確認：承認済みPNG、正式な色・書体規定、対象組織のアクセス管理、クラウドSupabase接続、本番メール・公開ドメイン。ロゴを勝手に再現しない。
